# CLARA simulator working agreement

- Do not use emojis.
- Use synthetic data only. Keep CLARA prediction disabled unless the user explicitly changes that scope.
- Keep source-derived product concepts distinct from hypothetical simulation assumptions.
- Run `node tests/sim.mjs` after simulation changes and perform browser checks for interface changes.
- Check in completed changes to `https://github.com/paulin/clara_sim.git` with a descriptive commit and push them after verification, as requested by the user. Preserve existing history; never force-push without explicit authorization.
- Continue publishing app changes to the existing private Site identified in `.openai/hosting.json`, preserving its audience.
- Do not commit credentials, generated deployment archives, or temporary files.
